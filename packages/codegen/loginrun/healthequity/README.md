# LoginRun Codegen Demo Output

This folder was generated by `npx @loginrun/codegen demo`.

The mock demo uses bundled redacted HealthEquity-style artifacts. It does not submit credentials, request OTP, call LoginRun APIs, or require Browserless configuration.

## Files

- `login-site.json`: site profile draft for deterministic login onboarding.
- `report.md`: Codegen summary with selected candidates and evidence.
- `fixtures/`: redacted runtime inventory and candidate score artifacts.
- `tests/`: generated fixture regression test.
